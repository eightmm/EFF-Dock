# Prism manuscript files

Upload main.tex, SI.tex, references.bib, and the assets and data folders together. main.tex contains the article; SI.tex contains the Supplementary Information. Figure PDFs retain their original vector graphics. figure_captions.md provides the corresponding LaTeX captions. main.pdf and SI.pdf are compiled previews. The data folder contains verified numerical source data and figure provenance.

Before journal submission, the authors must confirm research funding and the complete all-author competing-interest declaration.
