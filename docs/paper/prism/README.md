# Prism reference package

[Download the ZIP](prism_figure_reference.zip) for the combined figure PDF,
14 individual PDFs, English captions, a source manifest and the LaTeX reference
document (`main.tex`, `figure_captions.tex`). ZIP paths are self-contained.

The current repository sources are [the captions](../FIGURE_CAPTIONS.md),
[manifest](../manifest.json) and [page index](../README.md). Figure numbering and
placement are provisional. Adapt the blocks and bibliography keys to the manuscript.
Use XeLaTeX or LuaLaTeX; compilation has not been verified locally.

PB-invalid hatching, RMSD-only oracle, confidence ranking versus generation order,
query-normalized sequence identity, and sample SD versus 95% CI retain their
caption definitions. These files are manuscript working materials.
