# Shared pastel palette

Blue #8FB9D8, peach #E8B395, mint #9AC9B4, lavender #B8A6CE,
blue-gray #B9C3CE, light blue #B1CDDF.
All 14 selected manuscript figures use these colors consistently where the
same semantic roles recur. Neutral text and SD bars retain dark contrast.
PB-valid is solid; PB-invalid extensions are hatched.
Pocket/prior heatmap uses a focused cool-to-warm palette: teal at 70%, cream
at 75%, coral at 80%; fixed linear numerical range 50–100%. Color anchors
concentrate hue contrast in 70–80%; 75% is not a statistical threshold.
Data, thresholds, axes and panel ordering are unchanged.

Stacked PB-valid/PB-invalid bars use identical nominal widths/heights and zero
patch-outline width, preventing white solid borders and colored hatch borders
from creating an apparent overhang. Hatch strokes remain enabled.
