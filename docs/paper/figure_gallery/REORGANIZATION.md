# 현재 구성

기존14페이지를 핵심11개+보충3개로 재구성한 단일14페이지 PDF.

- 사용자 요청으로 예산/guidance 성능(6페이지)과 runtime·memory(7페이지)를 다시 분리. Runtime·memory는 A/B 한 장으로 유지.
- 예전3(Top-k 요약/포즈 밀도),9(실패 분해),14(CI 상세)를 뒤쪽 보충으로 이동.
- CI 제목에 비교 방향·조건과95% CI를 명시.
- 복잡도15패널, 후보수, 순위/생성순서 누적은 각 질문과 가독성을 위해 별도 유지.
- 파스텔, PB-invalid 빗금/외곽선 수정, 1–20 확대창·25%격자·연결선 유지.
- 학습 관련성/리간드/서열별 성능은 분모와 조건이 달라 억지로 합치지 않음.
- 새 inference·통계 추정 없이 기존 집계값을 재배치. 전체 페이지 목록은 PDF_EXPORTS.md.
