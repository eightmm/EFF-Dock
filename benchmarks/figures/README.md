# Benchmark figures

Matplotlib and rendering scripts for benchmark comparisons live here. Source
tables and admitted result JSON/CSV files remain in `docs/results`; generated
images are written to `docs/results/**/figures` or ignored `outputs/figures`.

Figures must not silently embed replacement metrics. Values should come from a
tracked result table or an explicitly documented literature table, and the
caption must distinguish Top-1, Oracle, and PB-valid joint success.

- `plot_joint_oracle.py` renders the promoted early-time-50k/U70k stack as raw
  Top-1, refined Top-1, refined Joint, and refined Oracle-100 against both
  supplied-pocket literature baselines and completed local three-repeat
  reruns. Local reruns carry mean ± sample-SD error bars and remain visually
  distinct from values reported by papers.
- `plot_top1_oracle.py` renders the compact refined Joint/Oracle-100 view.
- Both read `docs/results/external_models/effdock_u70k_benchmark.json` and
  reject any comparison source not marked `supplied_pocket_only`.
- The expanded figure also reads
  `docs/results/external_models/pocket_only_executed_reruns.json`, generated by
  `benchmarks/external_models/build_executed_comparison.py` only after all
  three repeat summaries exist.

`scripts/figures` is a compatibility alias for archived commands and tests.
